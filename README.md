# Algorithm Visualizer

An interactive visualizer for five core algorithms, built for Round 2 submission.

## Live demo
https://rebeltalks.github.io/Algorithm-Visualizer/

## Algorithms included
- Bubble Sort
- Merge Sort
- Binary Search
- Breadth-First Search (BFS)
- Depth-First Search (DFS)

## Features
- Play, Pause, and Reset controls
- Adjustable animation speed
- Step-by-step visual breakdown of comparisons, swaps, and visits
- Randomized data on each run

## Tech stack
HTML, CSS, and vanilla JavaScript — no frameworks, no build step. Deployed with GitHub Pages.

## How to run locally
Clone the repo and open `index.html` in any browser — no installation needed.
